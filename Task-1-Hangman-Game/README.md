
# Task 1: Hangman Word Guessing Game

## Description

A console-based Hangman game developed using Python.
The player attempts to guess a randomly selected English
word one letter at a time.

## Features

- Random secret word selection
- Six incorrect guesses allowed
- ASCII gallows illustrations
- Tracking of previously guessed letters
- Duplicate guess protection
- Input validation
- Victory and defeat messages

## Requirements

- Python 3

No external libraries are required.

## How to Run

Open a terminal in this directory and run:

`python hangman.py`

On Windows, you can also run:

`py hangman.py`

## Concepts Practiced

- Functions and modular programming
- Strings and sets
- Loops and conditional statements
- Random selection
- User input validation
